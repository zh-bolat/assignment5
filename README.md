## Description

A small website with JavaScript tasks. A navbar links four pages:

- **Part 1: Intro** (`index.html`) — Task 0 (console.log, alert) and Task 1 (variables, operators, string concatenation). Results are in the browser console.
- **Part 2: DOM** (`dom.html`) — Task 2 (change paragraph text), Task 3 (change background color and font size), Task 4 (add/remove list items).
- **Part 3: Events** (`events.html`) — Task 5 (mouseover/mouseout), Task 6 (keyup live input), Task 7 (calculator).
- **Part 4: To-Do** (`todo.html`) — Task 8 (To-Do app: add, delete, mark as completed by clicking on the task; tasks are stored in an array).

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/zh-bolat/assignment5.git
   ```
2. Open `index.html` in a browser.
3. Open the console (F12) to see the output of Part 1.

Or just open the live site link above.
